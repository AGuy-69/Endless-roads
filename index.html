Endless Road

This game loads its sounds and car models from the assets folder, and browsers do not allow that when a page is opened by double-clicking it.

Run serve.bat (Windows) or serve.sh (Mac / Linux) in this folder. It starts a small local server and opens the game in your browser.

No script? Open a terminal here and run python -m http.server 8000, then visit http://localhost:8000/.
